# 🚀 GitHub Search - Petize Challenge

Desafio técnico desenvolvido para a vaga de Desenvolvimento Frontend na **Petize**. O projeto consiste em uma plataforma de busca de usuários do GitHub, exibindo perfis detalhados e repositórios com recursos avançados de UX.

---

## 🛠️ Tecnologias e Ferramentas

Para garantir performance, tipagem segura e uma interface moderna, utilizei:

- **React 19** + **Vite** (Build otimizado e rápido)
- **TypeScript** (Tipagem estrita para segurança de dados)
- **Chakra UI** (Design system responsivo e acessível)
- **Zod** (Validação de schemas e contratos de API/Entidades)
- **i18next** (Suporte completo a Internacionalização: PT-BR / EN)
- **React Infinite Scroll** (Carregamento sob demanda de repositórios)
- **Lucide React** (Ícones modernos)

---

## ✨ Funcionalidades Entregues

✅ **Busca de Usuários:** Integração com a API do GitHub com tratamento de erros.  
✅ **Páginas de Perfil:** Exibição de Bio, Redes Sociais, Seguidores e Repositórios.  
✅ **Scroll Infinito:** Carregamento performático de 10 em 10 itens conforme o scroll.  
✅ **Ordenação Dinâmica:** Filtro por nome de repositório (Crescente/Decrescente).  
✅ **Internacionalização:** Alternância de idioma (Português/Inglês) preservando o estado.  
✅ **Responsividade Total:** Interface adaptada para Mobile, Tablet e Desktop.  
✅ **UX Refinado:** Estados de Loading, Empty States e validação de "Usuário não encontrado".
